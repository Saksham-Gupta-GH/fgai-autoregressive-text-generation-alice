% Section 1
\sectiontitle{1. System Overview \& Problem Statement}
{\fontsize{8.5pt}{10.5pt}\selectfont
Four recurrent neural language models (Simple RNN, BiRNN with forward-backward final state concatenation [$h_n[-2], h_n[-1]$], LSTM, and GRU) were trained under strictly controlled conditions on \textit{Alice's Adventures in Wonderland}. To eliminate data leakage, the corpus is partitioned chronologically (80\% Train, 10\% Val, 10\% Test) and the vocabulary (1,300 tokens, \texttt{min\_freq=2}) is fitted exclusively on training tokens. Context sequence length is 6 tokens. Held-out test set has an 11.17\% \texttt{<unk>} token rate.
}\par

% Section 4
\sectiontitle{4. Conclusion \& Model Comparison}
{\fontsize{8.5pt}{10.5pt}\selectfont
\begin{itemize}[leftmargin=*,itemsep=1.5pt,topsep=0pt,parsep=0pt]
  \item \textbf{LSTM vs. GRU \& UNK Nuance:} LSTM leads across next-word prediction metrics (Val Loss 3.9903, PPL 54.07, Test Top-1 23.29\%), with GRU performing closely behind (Val Loss 4.0353, Test Top-1 22.53\%) with 11\% fewer parameters. Test targets include 11.17\% \texttt{<unk>} tokens due to train-only vocabulary fitting.
  \item \textbf{Qualitative Consistency \& Seed Origin:} Seed 1 comes from the training text, Seed 2 from held-out test text, and Seed 3 from validation text. Consistency was assessed qualitatively: at $T=0.5$, LSTM and GRU more frequently generate Carroll-style dialogue tags (`the march hare said'), though all models drift across multi-clause sequences without sustaining a persistent scene.
  \item \textbf{Single-Seed Limitation \& BiRNN:} \texttt{SEED=42} ensures strict comparability; the 0.045 loss gap between LSTM and GRU falls within single-run variance margins. BiRNN's forward-backward state concatenation feeds complete context, but its 1,262,868 parameters overfit by epoch 2 (val loss 4.2804).
  \item \textbf{Temperature Sampling:} $T = 0.5$ provides the optimal trade-off between lexical diversity (Distinct-1: 0.60--0.73) and phrase stability, achieving minimal trigram repetition (LSTM 5.0\%, GRU 0.0\%, BiRNN 1.0\%, Simple RNN 6.1\%).
\end{itemize}
